# powerbi-monthly-sales-analysis
Power BI dashboard analyzing one-year monthly sales trends.
## Executive Monthly Sales Trend Analysis

### Overview
This project analyzes one-year monthly sales performance to identify seasonal patterns and overall revenue trends. The dashboard provides a high-level view of business momentum and supports planning and performance monitoring decisions.

### Business Objective
- Analyze month-to-month revenue trends
- Identify seasonal peaks and dips
- Establish a baseline for sales performance

### Dataset
- Source: Kaggle Retail Sales Dataset
- Type: Transaction-level sales data
- Time Period: 1 year

### Tools Used
- Power BI
  - Power Query
  - DAX
  - Data Modeling

### Key KPI
- Total Revenue

### Dashboard
The dashboard includes a line chart visualizing monthly revenue trends across the year.

### Key Insight
Sales peaked in May, indicating seasonal demand, while September recorded the lowest sales, suggesting a post-peak demand slowdown.
